01 · Foundations

What is a Magnitude Comparator?

A combinational logic circuit that compares two binary numbers and reports their relative size.

A magnitude comparator takes two n-bit binary numbers, A and B, and determines whether A is greater than, equal to, or less than B — producing three mutually exclusive outputs: A>B, A=B, and A<B.

  • Why it's needed: processors, memory controllers and embedded systems constantly have to decide "which value is bigger" — sorting, address decoding, range checks and loop conditions all reduce to this comparison.
  • Real-world uses: ALUs use comparators for branch conditions; routers use them for priority queues; industrial controllers use them for threshold checks.
  • Comparator vs. equality comparator: an equality comparator (built from XNOR gates) only answers "are they equal?" — a single bit output. A full magnitude comparator goes further, ranking the two numbers with three distinct outputs, so it needs extra logic to resolve inequality direction, not just mismatch.
02 · Building Blocks

Types of Comparators

From a single bit to n bits — the same principle scales through cascading.

1-bit Comparator

2 inputs3 outputsXNOR core

Compares single bits A and B. Since a bit can only be 0 or 1, the logic is simple: A>B only when A=1,B=0; A<B only when A=0,B=1; and A=B when both bits match (an XNOR relation).

A>B = A·B'   A<B = A'·B   A=B = A⊙B

2-bit Comparator

4 inputs16 rowsMSB priority

Compares A = A1A0 against B = B1B0. The most significant bit decides first — only if the MSBs are equal do the LSBs get a chance to break the tie. This "priority" idea is exactly what lets the design cascade to any bit width.

A>B = A1B1' + (A1⊙B1)A0B0'
A<B = A1'B1 + (A1⊙B1)A0'B0
A=B = (A1⊙B1)(A0⊙B0)

4-bit Comparator

8 inputsIC 7485Cascadable

Extends the same MSB-priority rule across 4 bit pairs (A3A2A1A0 vs B3B2B1B0). This is the classic 74LS85 IC — it even exposes cascading inputs so several 4-bit chips can be chained to compare 8, 12, or 16-bit numbers.

Comparison proceeds bit-by-bit from MSB (A3,B3) down to LSB (A0,B0). The first unequal pair, starting from the top, decides the result; if all four pairs match, A=B.

n-bit Comparator

GeneralizedRecursive logic

For n bits, the recursive rule is: examine bits from MSB (index n−1) to LSB (index 0). At each position, if the bits differ, that position alone determines A>B or A<B; if they are equal, move to the next lower bit. If every bit pair matches, A=B.

for i = n−1 downTo 0:
  if Ai ≠ Bi: result = (Ai > Bi) ? "A>B" : "A<B"; stop
if no differing bit found: result = "A=B"

06 · Signal Flow

Working Principle

How a comparison request moves through the circuit, gate by gate.

1

Inputs enter

Bits A and B are applied to the primary input lines. Two NOT gates invert them to generate the complements A′ and B′.

2

Four AND gates evaluate in parallel

A·B′ tests "A is 1 while B is 0" (A>B). A′·B tests the opposite (A<B). A·B and A′·B′ each test one of the two ways A and B can match.

3

OR gate resolves equality

An OR gate combines A·B and A′·B′ — it outputs 1 if either matching case is true, giving A=B = A·B + A′·B′.

4

Final output & LED

Exactly one of the three output lines goes high. That line drives its LED, so the result is visible instantly — this is the signal you toggled above.
